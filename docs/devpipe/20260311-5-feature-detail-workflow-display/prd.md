# 详情页工作流进度条

## 需求背景

详情页目前只展示静态信息，缺少对开发工作流阶段进度的可视化展示。开发者需要直观地看到当前分支处于工作流的哪个阶段。

## 需求描述

在详情页添加阶段进度条，用颜色区分已完成、进行中、待执行的阶段，并根据 `dev_type` 适配不同的阶段流程。

### 功能要求

1. 阶段进度条横向排列，展示所有适用阶段
2. 已完成阶段显示绿色，进行中阶段显示蓝色脉冲动画，待执行阶段显示灰色
3. 新功能类型包含 discuss 阶段，优化重构和 Bugfix 跳过 discuss
4. 进度条下方展示 Timeline 分组：环境准备、工作流程、总结复盘

### 涉及模块

| 模块 | 说明 |
|------|------|
| `dashboard/src/worktree_service.py` | 阶段计算逻辑和 Timeline 分组 |
| `dashboard/templates/detail.html` | 进度条 HTML 和 CSS |

## 验收标准

1. 进度条正确展示各阶段状态（已完成/进行中/待执行）
2. 新功能类型显示 discuss 阶段，其他类型跳过
3. Timeline 分组正确归类各阶段
4. 进行中阶段有视觉动画效果
