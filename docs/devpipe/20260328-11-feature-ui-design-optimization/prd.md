# UI 整体设计优化

## 需求背景

Dashboard 当前使用基础样式，视觉效果较为简陋。参照 VoltAgent 等现代开发工具的暗色主题设计，需要对整体 UI 进行视觉升级。

## 需求描述

基于 DESIGN.md 设计规范，实施全面的 UI 视觉优化。采用暗色主题设计系统，使用 CSS 自定义属性管理设计令牌，优化卡片布局、进度条样式和响应式适配。

### 功能要求

1. 建立 CSS 自定义属性（Design Token）体系：颜色、间距、圆角、阴影
2. 暗色主题配色方案：深色背景、高对比度文本、渐变强调色
3. 卡片组件重设计：毛玻璃效果、悬浮阴影、过渡动画
4. 进度条视觉优化：渐变色填充、阶段图标、时间线连接线
5. 向导界面样式升级：步骤指示器、表单控件、按钮系统
6. 响应式布局：适配桌面和平板尺寸
7. 排版系统：字体层级、行距、间距规范

### 涉及模块

| 模块 | 说明 |
|------|------|
| `dashboard/static/css/` | CSS 样式文件 |
| `dashboard/templates/` | HTML 模板更新 |

## 验收标准

1. 暗色主题一致应用到所有页面
2. CSS 自定义属性正确管理所有设计令牌
3. 卡片悬浮交互效果流畅
4. 响应式布局在不同屏幕宽度下正常展示
5. 视觉效果接近 DESIGN.md 设计稿
6. 无样式闪烁和布局抖动
