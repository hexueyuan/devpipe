## 问题与解决方案记录

### 问题 1：CSS 变量在旧版浏览器的 fallback

CSS 自定义属性（CSS Variables）在部分旧版浏览器中不被支持，导致样式完全失效。解决方案是为所有使用 CSS 变量的关键样式属性添加 fallback 值，将固定值写在 var() 声明之前，确保不支持 CSS 变量的浏览器也能正确渲染基本样式。
