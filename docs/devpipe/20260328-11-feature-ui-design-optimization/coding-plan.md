## 技术方案

建立 CSS 自定义属性（CSS Variables）体系，统一管理颜色、间距、圆角、阴影等设计令牌。以暗色主题为基础定义主色、辅色、背景色、文本色等变量，确保全站视觉风格一致。所有组件样式引用变量而非硬编码值，为后续主题切换预留扩展点。

卡片组件重设计重点优化视觉层次和交互体验，包括调整卡片内边距和间距比例、优化阴影和边框效果、增加 hover 状态的微交互动画。进度条视觉优化包括节点大小和连接线粗细调整、状态颜色对比度优化、动画过渡效果。向导样式升级统一步骤指示器、表单控件和按钮的视觉风格。

响应式布局采用 CSS Grid 和媒体查询实现，确保 Dashboard 在桌面端和平板端均可正常使用。排版系统定义标题、正文、标签等文本元素的字号、行高和字重层级，建立清晰的视觉层次。

## 验收标准

1. 暗色主题视觉风格全站一致，无色彩不协调区域
2. 卡片 hover 交互流畅，进度条动画自然
3. 响应式布局在不同屏幕宽度下正常显示，无溢出或错位
