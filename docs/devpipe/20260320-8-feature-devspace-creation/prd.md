# 开发空间创建功能

## 需求背景

开发者目前需要手动执行多个命令来创建开发空间（git worktree、Docker 容器、tmux 会话），流程繁琐且容易出错。需要一个可视化向导来简化创建流程。

## 需求描述

提供 4 步向导式开发空间创建功能：选择 Issue、填写开发信息、确认分支、执行创建。支持异步创建和实时进度反馈。

### 功能要求

1. 步骤一：从 GitHub 仓库获取 Issue 列表，支持选择或跳过
2. 步骤二：填写开发类型（新功能/优化重构/Bugfix）、功能描述
3. 步骤三：自动生成分支名，确认创建参数
4. 步骤四：异步执行创建流程（git worktree add → Docker 容器创建 → tmux 会话），实时显示进度
5. 创建完成后提供"进入开发空间"按钮

### 涉及模块

| 模块 | 说明 |
|------|------|
| `dashboard/src/devspace_service.py` | 开发空间创建服务层 |
| `dashboard/src/app.py` | 创建 API 路由 |
| `dashboard/templates/` | 向导 UI 模板 |

## 验收标准

1. 向导 UI 可正确切换 4 个步骤
2. Issue 列表从 GitHub API 正确获取
3. 创建流程异步执行，前端实时显示进度
4. 创建完成后可通过按钮进入开发空间
5. 创建失败时显示错误信息
