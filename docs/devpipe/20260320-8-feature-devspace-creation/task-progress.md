## 问题与解决方案记录

### 问题 1：Docker 容器创建超时

创建开发空间时需要拉取 Docker 镜像，首次拉取耗时较长，容易触发默认超时导致创建失败。解决方案是增大超时时间阈值，并在前端实现异步进度反馈机制，通过轮询接口展示当前创建步骤（镜像拉取、容器创建、环境初始化等）的实时状态。
