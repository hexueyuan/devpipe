## 技术方案

新增 `devspace_service.py` 服务层，封装开发空间创建的核心逻辑，包括 git worktree 创建、Docker 容器启动、volume 挂载和 tmux 会话初始化。服务层对外提供统一接口，屏蔽底层命令行调用细节。

Flask 端新增创建 API 端点，接收前端提交的创建参数（分支名、开发类型、Issue 编号等），调用 `devspace_service.py` 执行创建流程。API 采用异步模式，创建任务提交后立即返回任务 ID，前端通过轮询或 SSE 获取创建进度。

前端向导 UI 分 4 个步骤引导用户完成创建：(1) 选择开发类型 (2) 填写分支名和描述 (3) 关联 Issue (4) 确认并创建。创建过程中展示实时进度反馈，包括各步骤的执行状态和日志输出。错误处理覆盖常见失败场景（如分支已存在、Docker 不可用等），支持失败后重试。

## 验收标准

1. 4 步向导流程引导正确，参数校验完整
2. 异步创建过程有实时进度反馈，用户体验流畅
3. 常见错误场景处理到位，支持失败重试
