## 技术方案

在 `worktree_service.py` 中定义 `STAGE_META` 元数据结构，为每个工作流阶段配置角色图标（如 discuss 对应产品经理图标、coding 对应开发者图标、review-and-fix 对应审查者图标）和显示名称等元信息。

阶段耗时计算基于 `context.json` 中记录的时间戳数据，通过计算相邻阶段完成时间的差值得出每个阶段的实际耗时。耗时格式化为人类可读形式（如"2 小时 15 分钟"或"1 天 3 小时"），处理边界情况如阶段尚未完成时显示"进行中"。

前端 Timeline 分组 UI 增加角色图标和耗时信息展示，每个阶段分组的标题区域左侧显示角色图标，右侧显示耗时。CSS 样式确保图标大小一致、时间文本对齐，整体视觉风格与现有 Dashboard 主题协调。

## 验收标准

1. 各阶段耗时数据正确计算并以可读格式显示
2. 角色图标与对应阶段正确匹配
3. Timeline 分组同时展示角色图标和耗时信息，布局协调
