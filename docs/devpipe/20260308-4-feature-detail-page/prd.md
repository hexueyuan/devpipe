# 详情页

## 需求背景

列表页展示了所有开发分支的概览信息，但开发者需要查看单个分支的完整开发上下文，包括子任务列表、验收标准等详细信息。

## 需求描述

点击列表项进入详情页，展示完整的开发上下文信息，包含子任务表格、验收标准列表，并提供返回列表的导航。

### 功能要求

1. 新增详情页路由 `/detail/<name>`
2. 展示完整的开发上下文信息：分支名、开发类型、描述、创建时间
3. 从 `task-progress.md` 解析子任务表格，以网格形式展示
4. 从 `prd.md` 或 `coding-plan.md` 解析验收标准列表
5. 提供返回列表页的导航链接

### 涉及模块

| 模块 | 说明 |
|------|------|
| `dashboard/src/app.py` | 新增详情页路由 |
| `dashboard/src/worktree_service.py` | 子任务解析、验收标准解析 |
| `dashboard/templates/detail.html` | 详情页模板 |

## 验收标准

1. 点击列表页卡片可跳转到对应的详情页
2. 详情页正确展示分支基本信息和子任务网格
3. 验收标准列表正确解析和展示
4. 可从详情页返回列表页
