# 详情页开发方案

## 子任务分解

| # | 子任务 | 模块 | 状态 |
|---|--------|------|------|
| 1 | 详情页路由和数据聚合 | app.py | 已完成 |
| 2 | 详情页模板框架 | templates/detail.html | 已完成 |
| 3 | 子任务网格展示 | worktree_service.py + templates/ | 已完成 |
| 4 | 验收标准区域和列表导航 | templates/ | 已完成 |

## 技术方案

在 `app.py` 中新增详情页路由，接收 worktree 名称作为路径参数，通过 `worktree_service.py` 聚合该 worktree 的完整上下文数据，包括基本信息、子任务列表、验收标准等，传递给详情页模板渲染。

详情页模板 `detail.html` 采用分区布局，顶部展示基本信息（分支名、开发类型、阶段状态），中部以网格形式展示子任务列表及其完成状态，底部展示验收标准。子任务数据从 `task-progress.md` 文件中解析获取。

页面顶部提供返回列表页的导航链接，确保用户可以在列表页和详情页之间顺畅切换。验收标准区域以勾选列表形式呈现，直观展示各项验收条件的满足情况。

## 验收标准

1. 详情页正确展示 worktree 的完整开发上下文信息
2. 子任务网格正确显示各子任务名称、模块和完成状态
3. 列表页和详情页之间导航正常，链接无断裂
