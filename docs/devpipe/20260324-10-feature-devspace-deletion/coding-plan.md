# 开发空间删除功能方案

## 子任务分解

| # | 子任务 | 模块 | 状态 |
|---|--------|------|------|
| 1 | 资源探测逻辑 | devspace_service.py | 已完成 |
| 2 | 清理执行逻辑 | devspace_service.py | 已完成 |
| 3 | 向导 UI 3 步骤 | templates/ | 已完成 |
| 4 | 确认流程和强制选项 | templates/ + app.py | 已完成 |

## 技术方案

在 `devspace_service.py` 中实现资源探测逻辑，删除前自动扫描目标开发空间关联的所有资源，包括 git worktree 目录、git 分支、Docker 容器（运行中或已停止）、Docker volume 和 tmux 会话。探测结果以结构化数据返回，供前端展示。

清理执行逻辑按依赖关系确定安全的清理顺序：先终止 tmux 会话，再停止并移除 Docker 容器，然后移除 Docker volume，接着清理 git worktree，最后删除 git 分支。每步操作独立执行并记录结果，某步失败不阻塞后续步骤。

前端向导 UI 分 3 个步骤：(1) 选择要删除的开发空间 (2) 展示将被清理的资源列表供用户确认 (3) 执行删除并展示结果。提供强制删除选项，跳过未合并分支等安全检查，适用于需要强制清理的场景。

## 验收标准

1. 资源探测正确识别开发空间关联的所有资源
2. 清理执行顺序安全，各步骤独立处理失败
3. 删除前有二次确认流程，强制选项工作正常
