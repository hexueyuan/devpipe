# 开发空间删除功能

## 需求背景

开发完成后，开发者需要清理不再使用的开发空间（worktree、Docker 容器、数据卷等），手动清理容易遗漏资源。需要安全的清理向导。

## 需求描述

提供 3 步清理向导：环境探测、变更警告、执行清理。确保在清理前充分告知风险，防止误删有用数据。

### 功能要求

1. 步骤一：自动探测开发空间关联的所有资源（worktree、容器、数据卷、分支）
2. 步骤二：检查未提交变更和未推送 commit，显示警告信息
3. 步骤三：确认后执行清理，按序删除容器 → 数据卷 → worktree → 分支
4. 提供"强制清理"选项，跳过未提交变更检查

### 涉及模块

| 模块 | 说明 |
|------|------|
| `dashboard/src/devspace_service.py` | 资源探测和清理执行逻辑 |
| `dashboard/src/app.py` | 清理 API 路由 |
| `dashboard/templates/` | 清理向导 UI |

## 验收标准

1. 资源探测正确识别所有关联资源
2. 未提交变更时显示警告且需二次确认
3. 清理按正确顺序执行，避免依赖冲突
4. 清理完成后列表页正确更新
