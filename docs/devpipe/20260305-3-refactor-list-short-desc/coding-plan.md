# 列表页简短描述展示方案

## 子任务分解

| # | 子任务 | 模块 | 状态 |
|---|--------|------|------|
| 1 | description 字段读取和传递 | worktree_service.py | 已完成 |
| 2 | 长文本截断和卡片布局调整 | templates/ + static/css/ | 已完成 |

## 技术方案

在 `worktree_service.py` 中扩展数据读取逻辑，从 `context.json` 中提取 `description` 字段并传递给模板层。该字段存储开发任务的简短描述信息，用于在列表页卡片中为用户提供快速概览。

前端卡片布局增加描述文本区域，使用 CSS `text-overflow: ellipsis` 和 `-webkit-line-clamp` 实现多行文本截断，确保长描述不会撑破卡片布局。截断后显示省略号，鼠标悬停时通过 `title` 属性展示完整内容。

## 验收标准

1. 列表页卡片正确显示开发任务描述信息
2. 长文本自动截断并显示省略号，不破坏卡片布局
